# Política de seguridad

- Notifique vulnerabilidades de forma privada mediante *GitHub Security Advisories* del repositorio.
  No abra Issues públicas con detalles explotables.
- Tiempo objetivo de primera respuesta: 5 días laborables.
- Alcance: código de `web/`, `ml/`, workflows de `.github/` y configuración de `config/`.
- Modelo de amenazas y controles: `docs/05-seguridad.typ` (AURA-DOC-05).
- Protección de datos: `docs/06-proteccion-datos.typ` (AURA-DOC-06). La aplicación no recoge datos
  personales de usuarios finales; cualquier hallazgo que lo contradiga se trata como incidente
  (arts. 33–34 RGPD).
